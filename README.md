# 🌿 EcoScan

Сканер экологичности продуктов. Сканируй штрих-код — узнай экологический рейтинг, состав и найди зелёную альтернативу.

## Фичи MVP
- 📷 Сканер штрих-кодов (EAN-13, UPC)
- 🌱 Экологический рейтинг (A–F)
- 📦 Локальная база 50K+ продуктов
- 📜 История сканов
- 💎 Подписка Eco+ (детальный разбор, офлайн-режим)

## Стек
- Flutter 3.24+
- Hive (локальное хранилище)
- mobile_scanner (камера/штрих-коды)
- RevenueCat (покупки в приложении)
- Provider (state management)
